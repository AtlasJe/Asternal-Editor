## 状态覆盖与补片

- 草地／泥土合并为 `terrains/ground.png`，标签为“草地”“泥土”，空白或其他地形邻居按草地处理。草地作边界材质，保持纯草地外观，不开启 `boundaryTransitions`；泥土瓦片在本格内部携带草地边缘，不需要在草地中心再画泥土。
- 原 0、1、2 和 13 张泥土图逐像素保留，不再去掉草地颜色。原图依原组合关系排列，草地变体和无装饰泥土权重为 8，其他草地变体权重为 1；权重只作用于同一套九宫格标注。
- 原生泥土覆盖 13 种形状，补齐 34 种，合计 47 种有效形状：8 邻域共 256 种，当斜角相邻的两条直边都为泥土时才约束斜角，否则斜角归草地。所有组合有零冲突匹配，包含孤立格、横竖窄条、端头、内凹角、孔洞和对角占用。
- 每个补片的四象限由其同方向原图象限拼成：两条直边都不接泥土取外角 12/14/36/38；只接横向取上/下边 13/37；只接纵向取左/右边 24/26；两条直边都接时，斜角为泥土取内部 25，否则取内凹角 39/40/42/41。完整原生形状优先用原图，不用补片替代。`ground-supplements.json` 逐块记录九宫格及 TL/TR/BL/BR 四个来源编号。补片编号从 1000 开始以满足地图原生数字变体序列化约束，不代表原包文件。
- 对角占用保持分离，不跨空格架桥；此处没有 Dual mask。`review/dirt-shapes.png` 展示矩形、孔洞、内凹角、窄条、孤立格及对角形状，`review/ground-wang.png` 展示原图及全部补片。
- 删除 `terrains/grass.png`、`terrains/dirt.png` 及其 meta，**不保留兼容入口**：旧 Dual 格子表示占用，新 Wang 格子表示材质，不能只沿用旧 UUID 假装兼容。新地表有独立 UUID，其他物体及地形的原路径 UUID 不变。没有自动迁移旧地图；用过旧 Dual 入口的地图需重新铺该部分地表。
- 木栅栏原始状态：1→71、2→80、3→68、4→47、5→59、6→44、8→82、9→70、10→45、12→46。0、7、11、13、14、15 缺失，用 59 的上下纵杆、81 的左右横梁和 45 的中心柱组合补齐。没有旋转带光照的图。
- 原角件的纵向接口比直杆宽一像素；仅把 3、9 的顶端和 6、12 的底端两像素规范成 59 的接口。像素测试逐一检查所有开口、闭口及互相连接的接口 RGBA 完全一致。
- 56、58 是 59 的同功能纵杆画法，69 是已有端柱的替代外观；合并进栅栏规则，**不保留兼容入口**，避免用户面对同功能重复入口。栅栏 UUID 保持原路径身份。
- 两种林缘、城堡拼建只支持精确手动选片，不自动推测邻域；因此不存在缺片时静默选不相关自动图的问题。林缘原图不作为独立完整树丛物体。
- 城堡完整预设与手动拼建用途不同：前者一次放置整座结构并参与物体排序，后者允许自定义尺寸。房屋屋顶不再额外暴露同功能碎片。
- 未改原始图；切片、透明处理、合成、补片、去重、元数据及审阅图均由脚本生成。`write_pack()` 写 meta、保持既有路径 UUID；转换只清理本包废弃运行产物。

## 重建及验收

在项目根目录运行：

```sh
python3 asset-conversion-examples/kenney_tiny-town/convert/convert_tiny_town.py
node --experimental-default-type=module tests/test_tiny_town.mjs
python3 tests/test_tiny_town_pixels.py
python3 tools/tilemap.py index
python3 tools/tilemap.py build
```

脚本接受可选的原包路径及 `--out <目录>`；省略时读上一级原包、写 `packs/kenney-tiny-town/`。

已验证：全部来源有用途记录；原包文件字节核对；草地、泥土共 512 个真实绘制邻域，3×3 原图选片；所有 Edge mask；显式互相连接与单边连接无效；精确手动选片和分隔格禁选；覆盖、擦除、撤销、重做、原生地图序列化后重新读取；静态资源没有动画；底边锚点公式；实际 PNG 的栅栏接口、地表全部原图像素不变、过渡保持不透明、房屋墙面不漏底、拱门透明通道；全部输出文件有 meta；重复运行及临时目录输出逐文件一致；索引和离线单文件已重建。

已目视：脚本输出的房屋/植物/物品总览、Wang 原图和补片、泥土复杂形状、栅栏状态；上一轮已确认真实 Canvas2D 编辑器能选择本包、显示中文分类；本次 Wang 修改以原生模型测试及输出图验收，未重新执行浏览器交互验收。

限制：真实编辑器中的鼠标绘制未获得可确认的画面变化，操作行为以编辑器原生模型集成测试验收；未宣称完成手工画图或完整面板滚动/缩放测试。无动画需播放。未对每一种跨物体遮挡关系进行人工检查。
