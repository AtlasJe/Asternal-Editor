Documentación

Asternal Editor es un editor experimental de juegos 2D que funciona en el navegador. Organiza una escena y define comportamientos conectando nodos.

ALPHA · v0.1.0

Empezar

Abre Proyectos y crea uno. El editor empieza en Escena. Pinta el terreno y coloca objetos sobre el mismo espacio; Lógica y Recursos son vistas complementarias.

Nodos disponibles

  • Eventos: Al iniciar, Cada fotograma, Al pulsar tecla.
  • Acciones: Mover objeto, Cambiar propiedad, Condición.
  • Conecta la salida de un nodo con la entrada de otro.

Guardar

Los proyectos se guardan en el almacenamiento local del navegador. Cada dirección —por ejemplo localhost y GitHub Pages— mantiene su propia biblioteca.

Imágenes

Importa PNG, JPEG o WebP de hasta 2 MB. Las imágenes añadidas pueden convertirse en sprites dentro de la escena.

Límites actuales

Esta versión todavía no exporta proyectos, no ofrece físicas completas ni publica directamente en Builda H5. El terreno y los objetos se guardan juntos en la escena y aparecen en la vista previa.

Desarrollo y contribuciones

Para ejecutar Asternal Editor localmente, desde la carpeta del repositorio usa python -m http.server 8000 --bind 127.0.0.1 y abre http://127.0.0.1:8000/. Consulta el README en GitHub y el detalle de funciones y límites de la Alpha.
