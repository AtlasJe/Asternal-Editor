## Asset description (written by the author)

# Editor de mapas de píxeles y UI

Editor en el navegador para mapas de juegos con pixel art y diseños de UI. Pinta terrenos Dual basados en la ocupación de las esquinas, conexiones Edge y transiciones Wang; combina terrenos elevados, capas, objetos y sprites animados. Incluye implementaciones en Canvas2D y PixiJS, recursos para ejecución, mapas de ejemplo y ejemplos de conversión.

## Vista previa en línea

Explora el mapa de un puesto en el desierto incluido, mantén presionado para pintar, arrastra para desplazar la vista y prueba las herramientas de terreno, objetos, capas y UI. La interfaz está principalmente en chino. Los cambios son temporales: no se puede guardar, exportar ni usar almacenamiento persistente, y se omiten las confirmaciones para descartar cambios. Recarga para restablecer el ejemplo.

## Después de descargar

Abre `地图编辑器.html` en un navegador moderno para usar el editor completo sin instalación ni conexión a internet. Para desarrollar el código fuente, ejecuta `python3 -m http.server 8000` en la raíz del proyecto y abre `/web/`. Volver a compilar requiere Python 3.10+, Node.js 18+ y npm; la primera compilación descarga esbuild. El renderizador opcional de PixiJS carga PixiJS 8.6.6 desde una CDN, a menos que lo empaquetes localmente.

Empieza con [README.md](README.md), la [guía de integración y extensión](docs/integration.md), las [herramientas de compilación](tools/README.md) y la [guía de conversión de recursos](asset-conversion-examples/README.md). La documentación cubre el formato propio `.tilemap`, los UUID estables de los recursos, la integración en juegos y el uso en dispositivos móviles y con IA.

Para desarrolladores que crean juegos 2D o adaptan un editor. Los mapas usan un formato propio, no Tiled TMX; no se incluyen colisiones ni lógica de juego. Los mapas grandes pueden exigir muchos recursos en dispositivos móviles. Revisa las licencias de los recursos originales antes de reutilizarlos.

## Agrega tus propios recursos

Sube un paquete similar de recursos de pixel art junto con este proyecto a un asistente de programación con IA y pídele que siga la [guía de conversión de recursos](asset-conversion-examples/README.md) para recortar las imágenes y generar archivos `packs/<pack-id>/`, metadatos y UUID listos para el editor. También puedes describir terrenos, objetos o UI nuevos y pedirle que escriba programas de dibujo con Python/Pillow basados en los [ejemplos de generación de imágenes](image-generation-examples/README.md). Después de convertir o dibujar, actualiza el índice de recursos y vuelve a compilar el editor sin conexión como indica README.md.
