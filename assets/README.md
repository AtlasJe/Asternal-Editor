# Assets

- `images/`: sprites, texturas y hojas de animación.
- `audio/`: música y efectos.
- `fonts/`: fuentes del juego.
- `tilemaps/`: mapas `.tilemap` creados con el editor de Builda.
- `data/`: JSON y datos de configuración.

El paquete base de Builda mantiene sus recursos originales en `packs/` y su índice en `packs/index.json`. Los UUID existentes deben conservarse al añadir o convertir recursos.
